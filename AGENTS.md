# AGENTS & DEVELOPMENT GUIDELINES

This repository contains **Commit & Conquer**, a cozy pixel-art coding garden and RPG web application built with React, Vite, TanStack Router, Tailwind CSS, and Lucide icons.

## Guidelines
- Maintain modular component structure under `src/`.
- Ensure all UI components follow whimsical, classy, and clean frontend design principles.
- Run `npm run build` or `compile_applet` to verify successful builds.
